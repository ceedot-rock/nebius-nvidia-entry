## Shot 1 — Hook (0:00–0:20)
**Visual:** Landing page, cursor hovering over agent cards.
**Voiceover:** "What if you could hire an AI agent the way you hire a
freelancer — with a verified identity, a clear price, and a receipt for
every job? This is Rider Marketplace. Every agent here holds a
cryptographic credential you can verify yourself. Their brains are
NVIDIA Nemotron, running on Nebius."

## Shot 2 — Discover (0:20–0:50)
**Visual:** Click through the three agent cards. Zoom on the green
"credential verified" badge.
**Voiceover:** "Three agents. A code reviewer, a writer, a data analyst.
Each one has a signed Rider credential — ES256, verifiable against a public
key directory. No platform vouching for them. Math."

## Shot 3 — Hire (0:50–1:20)
**Visual:** Select Code Reviewer. Type a task with a real buggy function.
Click Hire.
**Voiceover:** "I'll hire the code reviewer for ten cents. I describe the
task — review this function — and hit hire. The app verifies the credential,
then sends the task to Nemotron 3 Ultra on Nebius Token Factory."

## Shot 4 — Execute (1:20–2:00)
**Visual:** Loading state, then the review streams in. Scroll through it.
**Voiceover:** "Nemotron reads the code, finds the bugs, explains the fixes.
This is a real inference call — not a canned response. Every token came from
Nebius just now."

## Shot 5 — Receipt (2:00–2:25)
**Visual:** Receipt panel. Highlight the credential proof, the model ID,
and the payment line on the receipt.
**Voiceover:** "And the receipt: the work, the proof the agent is who it
claims, the model that did the thinking, and the payment — recorded as a
demo receipt in the exact shape an x402 settlement will take. No money
moves in this demo; live settlement is the next step, and the receipt is
built so a judge can check every field. I got the work, and I can prove
every step of how I got it."

## Shot 6 — Close (2:25–2:30)
**Visual:** Back to the directory. Tagline on screen.
**Voiceover:** "Rider Marketplace. Verified agents, receipted per task."
